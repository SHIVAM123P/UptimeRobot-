# **App Name**: AlwaysUp

## Core Features:

- Uptime Monitoring: Monitor website uptime by periodically checking the provided URL.
- Status Display: Display the status of monitored websites (up or down) in a simple list.
- Interval Configuration: Allow users to configure monitoring intervals (e.g., 1-minute, 5-minute) with paid upgrades for shorter intervals.

## Style Guidelines:

- Primary color: Dark blue (#24292F) for a professional look.
- Secondary color: Light gray (#F6F8FA) for backgrounds.
- Accent: Teal (#2E9AFE) for status indicators and highlights.
- Minimalist design with a focus on clear status indicators.
- Simple icons to represent website status (e.g., a green checkmark for 'up', a red 'X' for 'down').
